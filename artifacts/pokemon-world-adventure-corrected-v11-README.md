# Pokémon Web 冒険・溜め技修正版 v11

統合版v10の冒険マップとバトル進行を見直し、操作方向、キャラクターの向き、町と冒険エリアの分離、ソーラービームなどの溜め技を修正した版です。レイド、フレンドバトル、育成、管理、図鑑は維持しています。

## 今回の追加

### 3D冒険マップとポケモンセンター

- 新規ユーザーはオーキド博士のポケモンセンターから始まり、全10地方の選択、地方ごとの御三家3匹の選択、Lv5での加入演出を行います。
- 地面をクリック／タップするとその場所へ移動し、建物本体または施設ラベルを押すと入口まで自動で歩いて入ります。
- PCはWASD・矢印、E・Space、Shift、右ドラッグでカメラ回転、ホイールでズーム、スマホは横画面のスティック・A・Bでも操作できます。
- 屋内・屋外とも、W／上は画面奥、S／下は画面手前へ進みます。カメラの向きから移動方向を計算し、キャラクターモデルの正面も進行方向へ合わせます。
- 画面右上に常時表示の「もどる」「メニュー」を追加しました。
- ポケモンセンター、町、冒険草原、岩山の洞窟、海岸と水辺を独立した3Dマップに分けました。地方ごとに空、地面、建物、天候、出現ポケモン、ジムを切り替えます。
- 建物は施設別の屋根、看板、庇、ガラス扉、窓、柱、玄関灯、植栽を持つモデルです。町には道路、広場、縁石、街灯、ベンチ、花、牧場柵、レイド結晶を配置しています。冒険草原には草むらと洞窟・海岸への入口、洞窟には岩壁と発光結晶、海岸には砂浜、水面、桟橋を配置しています。
- センター内は床タイル、導線カーペット、回復カウンター、回復装置、PC、通信端末、待合席、照明、植栽を配置し、俯瞰カメラを遮らない構造にしました。
- ポケモンセンター内に回復、ボックス・チーム、地方転送、通信交換、フレンドバトル、レイド案内を配置しました。
- 町にはセンター、ショップ、ジム、牧場、レイドステーションを配置し、野生ポケモンは出現しません。町の出口から別の冒険草原へ移動し、そこから洞窟と海岸へ進みます。
- 位置、移動距離、施設との距離、遭遇方法、歩数、遭遇間隔はサーバー側で検証します。
- 草むら、洞窟、釣り、波乗りで出現傾向が変わり、朝昼夕夜、天候、季節、地方も抽選へ反映します。
- 野生戦・トレーナー戦・ジム戦は現在位置から3Dバトル会場を自動選択します。全滅時はセンターへ戻り回復します。
- フレンドバトルの会場は挑戦者が選び、サーバーが保存した同じ会場を両者へ配信します。レイドは専用会場を維持します。

### レアバトルとチケット

- レアバトルは伝説、幻、特別な姿、メガ、キョダイマックスから抽選します。選択カテゴリに候補がない場合は、利用できる別のレア個体へ安全に切り替えます。
- レアバトルチケットを1枚消費して開始します。
- 通常の冒険バトルで相手を倒した時、または捕まえた時に、レアバトルチケットとレイドチケットをそれぞれ独立した2%抽選で獲得します。
- バッグとホーム上部へ所持数を表示します。専用PNGアイコンは `public/items` に同梱しています。
- レアバトルで捕獲した個体はLv1で保存し、「レアバトルのあかし」を付けます。

### レイド

- ★1〜★MAXをすべて選択できます。旧botの無効ランク設定には影響されません。
- 開始時、参加中の実ユーザーの誰か1人が持つレイドチケットを1枚だけ消費します。募集・参加・チーム選択では消費しません。
- 3人同期、ボス2回行動、再起動復旧、捕獲、図鑑、専用3D背景、味方3体同時描画、攻撃カメラを維持しています。
- ボスにも通常戦と同じ反動、吸収、状態異常、能力ランク、回復、次行動休み、天候、フィールド、溜め技を適用します。
- 一撃必殺はボスに無効、継続ダメージはレイド補正を使います。

### 個体育成

- 25性格の能力補正。
- 努力値は1能力252、合計510まで。相手種族の努力値を勝利時に加算し、6種の基礎ポイントアイテムも使用できます。
- 持ち物スロット。たべのこし、いのちのたま、こだわり系、きあいのタスキ、とつげきチョッキ、しんかのきせき、ゴツゴツメット、かいがらのすず、状態異常玉、主な状態回復きのみなどを戦闘へ接続しました。
- 戦闘で使える技を4つに制限し、それ以外は思い出し候補として保存します。個体詳細で入れ替えられます。
- 個体ごとの現在PPと最大PPを保存します。ピーピー系アイテムとポケモンセンターで回復できます。
- 種族データの fast / medium / medium-slow / slow / erratic / fluctuating 経験値タイプを使用します。
- レベルアップと基礎ポイント使用は現在のなつき度帯に応じて上昇します。フレンドボール、ゴージャスボール、やすらぎのすず、牧場、ひんしも反映します。
- ニックネーム、親ID・親名、出身、リボン、あかしを保存・表示します。レイド捕獲にはリボン、レア捕獲にはあかしが付きます。
- スターター、牧場孵化、通常捕獲、レア捕獲、レイド捕獲、進化、ヌケニン生成まで同じ個体形式へ統一しました。

### バトル

- HP、状態異常、PPを通常戦、フレンド戦、レイドの後も保存します。
- ポケモンセンターで全個体のHP、状態異常、PPを回復します。
- バトル中にキズぐすり系、状態回復、プラスパワー系を使用できます。きのみは条件成立時に自動発動します。
- 技ルールは、状態異常、能力上下、連続、固定、一撃必殺、吸収、反動、溜め、未来攻撃、カウンター、交代、場、天候、壁、設置技などの共通処理を通常戦・フレンド戦・レイドで共有します。
- ソーラービームなどの2ターン技は、最初のターンに攻撃軌道や命中演出を出さず溜め演出だけを表示します。次のターンは技ボタンを再選択させず、保存した技を自動発動します。PPは準備開始時の1回だけ消費します。通常戦、フレンド戦、レイドで同じ進行です。
- 特性は元Python版の特性に加え、タイプ無効・吸収、状態異常無効、火力・耐久補正などの主な特性を追加しました。
- NPCは残HP、相性、威力、回復、状態異常、能力変化を点数化して技を選びます。
- 全バトルの相手HUDに弱点と耐性を表示し、通常速度の演出時間を従来比1.15倍にしています。
- 元 `pokemon3.py` から抽出した汎用・固有技効果198定義を、通常戦エンジンで連続実行する回帰試験を追加しました。
- 個別技の追加効果データが壊れていてもリクエスト全体を500エラーにせず、その追加効果だけを中止します。通常戦・フレンド戦・レイドには状態を戻して安全処理を再試行する保護も追加しました。
- 命中しなかった技は攻撃軌道を相手の横へ外し、ダメージイベントがない攻撃で命中エフェクトを出さないようにしました。

### フレンドバトルと管理

- 通常、フラット50、ランクの3モード。ランクはLv50統一とEloレートを使い、ロビーにレートを表示します。
- 管理画面の所持金・アイテム操作を、Discord内ブラウザで動かない `prompt()` から画面内フォームへ変更しました。
- Discordサーバーの表示名を保存・同期し、管理画面の一覧と検索、個体の親名、図鑑の所持者表示へ使用します。IDは補助情報として小さく表示します。
- 管理画面ではユーザー表示名・ユーザー名・ID検索、所持金増減、アイテム付与、全回復ができます。出現率、レベル、地方設定は置いていません。
- 管理操作はログへ保存します。
- 通常プレイは許可されたDiscordサーバーのアクティビティ参加者全員が利用できます。管理画面と管理APIだけを `ADMIN_USER_IDS` に限定します。

### 図鑑・コレクション

- 進化前から分岐進化までをたどる進化系統図と、各進化条件を表示します。
- PokeAPIの生息地と、ゲーム内の地方・冒険での出現可否を表示します。
- レベルアップ、わざマシン、タマゴ技、教え技に分けて覚える技を一覧表示します。威力、命中、PPも確認できます。
- 高さと重さを表示し、高さは1.7mの人型との縮尺比較、重さは分かりやすい区分を表示します。

## 現時点の範囲

- ダブルバトルとトリプルバトルは未実装です。現在の画面、技対象、交代、AI、保存形式が1対1を前提としているため、専用の対象選択と複数枠同期が必要です。
- 全世代の全特性と全技の固有例外を網羅した状態ではありません。DBに登録済みの共通効果ルールと、エンジン内で明示した主要な固有技・特性を実行します。
- なつき度は、このWeb版で発生するレベルアップ、基礎ポイント、牧場、捕獲ボール、ひんしを反映します。本編の歩数、散髪、キャンプなど、このWeb版に存在しない行動は対象外です。
- リボン・あかしの保存欄とレイド／レア報酬は実装済みです。本編にある全種類の取得条件は未実装です。
- ランクは基本Eloです。シーズン、階級、マッチングキュー、使用禁止一覧は未実装です。
- NPC思考はヒューリスティック方式です。交代読みや長期的な詰み筋までは探索しません。

## アップロードと配置

まずWindows PowerShellでZIPをサーバーへ送ります。

```powershell
scp -i "$HOME\.ssh\talksurvivor_conoha_2026" "$HOME\Downloads\pokemon-world-adventure-corrected-v11.zip" root@160.251.143.172:/root/
ssh -i "$HOME\.ssh\talksurvivor_conoha_2026" root@160.251.143.172
```

SSH接続後、サーバー上で実行します。

```bash
rm -rf /root/pokemon-world-adventure-corrected-v11
mkdir -p /root/pokemon-world-adventure-corrected-v11
unzip -o /root/pokemon-world-adventure-corrected-v11.zip \
  -d /root/pokemon-world-adventure-corrected-v11
python3 /root/pokemon-world-adventure-corrected-v11/install-integrated.py
curl -fsS http://127.0.0.1:8501/api/health
```

インストーラは `/opt/games-pokemon`、`/opt/node22/bin/node`、`games-pokemon.service` 向けです。既知の旧版ハッシュを確認し、テスト、バックアップ、配置、再起動、ヘルスチェックを行います。途中で失敗した場合は旧版へ戻します。

`POKEMON_RAID_TEST_SOLO=1` は従来どおり有効にします。新しく作ったレイドは自分＋テストNPC2体で演出を確認できます。実ユーザー3人運用へ戻す場合は `/etc/games-party.env` の値を `0` にしてサービスを再起動してください。
